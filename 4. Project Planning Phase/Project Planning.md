# Project Planning

## Project Title

Auto Ticket Classification using Flow Designer

## Project Objective

The objective of the project is to automate the classification of school IT helpdesk tickets using ServiceNow Flow Designer.

The system identifies the issue from the Short Description and automatically assigns the appropriate Category and Subcategory.

## Project Phases

| Phase | Major Activities |
|---|---|
| Phase 1 | Requirement Analysis & Planning |
| Phase 2 | Backend Development & Configuration |
| Phase 3 | Automation using Flow Designer & Email Notification |
| Phase 4 | Testing, Validation & Security |
| Phase 5 | Deployment & Final Documentation |

## Phase 1 – Requirement Analysis & Planning

- Identify the school IT helpdesk problem.
- Define business requirements.
- Create the Project Update Set.
- Plan the required ticket classification process.

## Phase 2 – Backend Development & Configuration

- Create the Incident WorkFlow custom table.
- Configure required fields.
- Add Category, Subcategory and State choices.
- Implement dependency between Category and Subcategory.

## Phase 3 – Automation

- Create the Flow Designer flow.
- Configure the Record Created trigger.
- Add classification conditions.
- Automatically update Category and Subcategory.
- Configure email notification to the Caller.

## Phase 4 – Testing, Validation & Security

- Test ticket classification.
- Validate Category and Subcategory values.
- Check auto-generated ticket numbers.
- Verify email notifications.
- Validate data and access control.

## Phase 5 – Deployment & Documentation

- Complete the Project Update Set.
- Export the Update Set as XML.
- Prepare project documentation.
- Prepare the solution for demonstration and future use.

## Expected Outcome

The planned solution provides an automated, no-code process for classifying school IT helpdesk tickets and notifying the Caller after ticket creation.
