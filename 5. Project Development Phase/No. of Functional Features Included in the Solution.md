# No. of Functional Features Included in the Solution

## Overview

The Auto Ticket Classification project includes the following main functional features.

## Functional Features

### 1. Incident WorkFlow Table

A custom table is used to store school IT helpdesk ticket information.

### 2. Auto Number Generation

Each ticket receives an automatically generated ticket number.

### 3. Caller Information

The Caller field stores the user who submitted the IT support request.

### 4. Category Selection

The system supports four main categories:

- Network
- Hardware
- Access
- Performance

### 5. Subcategory Selection

The system supports the following subcategories:

- Wi-Fi
- Projector
- Forgot Password
- Slow Computer

### 6. Category and Subcategory Dependency

Subcategory options are dependent on the selected Category.

### 7. Automatic Ticket Classification

Flow Designer analyzes the Short Description and automatically identifies the issue type.

### 8. Automatic Category Assignment

The appropriate Category is automatically assigned based on the identified issue.

### 9. Automatic Subcategory Assignment

The appropriate Subcategory is automatically assigned along with the Category.

### 10. Email Notification

After classification, an automated email is sent to the Caller.

### 11. Structured Ticket Data

Ticket information is stored in a standardized custom table.

### 12. Update Set Deployment

The project configuration can be packaged using a Project Update Set and exported as an XML file.
