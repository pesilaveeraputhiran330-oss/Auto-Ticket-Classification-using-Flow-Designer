# Define Problem Statements

## Problem Statement

The school IT helpdesk receives different types of IT support incidents such as network, hardware, access, and performance-related issues.

Manually classifying these tickets and assigning the correct Category and Subcategory can take time.

## Problems Identified

### 1. Manual Ticket Classification
IT support tickets need to be classified based on the reported issue.

### 2. Inconsistent Classification
The correct Category and Subcategory may not always be selected consistently.

### 3. Time-Consuming Process
Manual ticket processing increases the time required to handle helpdesk requests.

### 4. Need for Automatic Notification
The Caller should receive a confirmation email after submitting a request.

### 5. Structured Ticket Information
Ticket information should be stored in a structured ServiceNow table.

## Proposed Problem Focus

Develop a ServiceNow Flow Designer automation that identifies the issue from the Short Description and automatically assigns the appropriate Category and Subcategory.

The system should also send a confirmation email to the Caller.

## Expected Outcome

The automation should reduce manual classification effort and provide a structured and maintainable ticket classification process.
