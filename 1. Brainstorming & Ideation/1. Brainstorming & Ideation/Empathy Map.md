# Empathy Map

## User

School IT Helpdesk User

## Says

- “My Wi-Fi is not working.”
- “The projector is not turning on.”
- “I forgot my password.”
- “My computer is slow.”

## Thinks

- Wants the IT issue to be identified correctly.
- Expects the support request to be processed properly.
- Wants confirmation after submitting the request.

## Does

- Reports the IT issue through the helpdesk.
- Provides a short description of the problem.
- Waits for the support request to be processed.

## Feels

- Concerned when an IT issue affects their work.
- Frustrated when the issue takes time to resolve.
- Satisfied when the request is correctly classified.

## Needs

- Easy ticket submission.
- Correct issue classification.
- Appropriate Category and Subcategory.
- Confirmation email after submitting the request.
