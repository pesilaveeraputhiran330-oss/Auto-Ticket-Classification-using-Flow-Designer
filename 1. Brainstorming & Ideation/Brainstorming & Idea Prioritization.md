# Brainstorming & Idea Prioritization

## Project Title

Auto Ticket Classification using Flow Designer

## Brainstorming

The school IT helpdesk receives different types of IT support incidents. Manually classifying these tickets and assigning the appropriate category can take time.

The proposed idea is to use ServiceNow Flow Designer to automatically classify IT helpdesk tickets based on the issue mentioned in the Short Description.

## Ideas Identified

- Automatically classify IT helpdesk tickets.
- Automatically assign the appropriate Category.
- Automatically assign the dependent Subcategory.
- Send a confirmation email to the Caller.
- Store ticket information in a structured ServiceNow table.
- Make the automation maintainable and scalable.

## Main Categories

- Network
- Hardware
- Access
- Performance

## Category and Subcategory Mapping

| Category | Subcategory |
|---|---|
| Network | Wi-Fi |
| Hardware | Projector |
| Access | Forgot Password |
| Performance | Slow Computer |

## Prioritized Solution

Automatic Ticket Classification using ServiceNow Flow Designer.

The flow identifies the issue from the Short Description and automatically updates the appropriate Category and Subcategory. It also sends a confirmation email to the Caller.
