# Project Demo Planning

## Project Title

Auto Ticket Classification using Flow Designer

## Demo Objective

The objective of the demonstration is to show how the ServiceNow Flow Designer automatically classifies school IT support tickets.

## Demonstration Sequence

### Step 1 – Introduction

Explain the problem of manually classifying school IT support tickets.

### Step 2 – Solution

Introduce the ServiceNow Flow Designer automation.

### Step 3 – Custom Table

Show the Incident WorkFlow table and its important fields.

### Step 4 – Flow Designer

Show the Auto Classify School IT Tickets flow.

### Step 5 – Create Test Ticket

Create a sample ticket with a Short Description.

### Step 6 – Automatic Classification

Show how the flow assigns Category and Subcategory.

### Step 7 – Email Verification

Show the email notification sent to the Caller.

### Step 8 – Deployment

Briefly explain the Project Update Set and XML export.

## Demo Outcome

The demonstration should show the complete working flow of the project from ticket creation to automatic classification and notification.
