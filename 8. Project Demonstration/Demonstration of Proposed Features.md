# Demonstration of Proposed Features

## Project Title

Auto Ticket Classification using Flow Designer

## Features Demonstrated

### 1. Incident WorkFlow Table

A custom Incident WorkFlow table is used to store IT support tickets.

### 2. Ticket Creation

A new ticket contains information such as Caller, Short Description and Description.

### 3. Automatic Classification

Flow Designer checks the Short Description and identifies the type of IT issue.

### 4. Category Assignment

The system automatically assigns the appropriate Category.

### 5. Subcategory Assignment

The system assigns the corresponding Subcategory based on the identified issue.

### 6. Email Notification

After processing the ticket, an email notification is sent to the Caller.

### 7. Update Set

The completed configuration can be exported using the Project Update Set as an XML file.

## Demonstration Example

Input:

**Short Description:** WiFi not working in library

Expected result:

**Category:** Network

**Subcategory:** Wi-Fi

An email notification is also sent to the Caller.

## Final Result

The demonstration shows the complete process from ticket creation to automatic classification and email notification.
