# Team Involvement in Demonstration

## Project Title

Auto Ticket Classification using Flow Designer

## Team Participation

The team members participate in the project demonstration by explaining different parts of the solution.

## Demonstration Responsibilities

### Project Introduction

Explain the problem statement, project objective and proposed solution.

### ServiceNow Configuration

Explain the Incident WorkFlow table, fields, categories and subcategories.

### Flow Designer

Explain the trigger, conditions, classification branches and update actions.

### Testing

Demonstrate sample tickets and verify the assigned Category and Subcategory.

### Email Notification

Show how the email notification is generated and verified.

### Deployment

Explain the Project Update Set and XML export process.

## Team Coordination

The team coordinates the demonstration so that each major part of the project is explained clearly and the complete workflow is demonstrated.

## Conclusion

Team involvement ensures that the project requirements, implementation, testing and demonstration are covered systematically.
