# Communication

## Project Title

Auto Ticket Classification using Flow Designer

## Project Overview

The project automates the classification of school IT support tickets using ServiceNow Flow Designer.

## Key Points to Communicate

- The system uses an Incident WorkFlow custom table.
- Tickets contain a Short Description and Description.
- Flow Designer automatically checks the Short Description.
- The appropriate Category and Subcategory are assigned.
- An email notification is sent to the Caller.
- The project configuration can be transferred using an Update Set.

## Demonstration Flow

The project can be explained in the following order:

1. Introduce the problem.
2. Explain the proposed solution.
3. Show the Incident WorkFlow table.
4. Show the Category and Subcategory fields.
5. Show the Flow Designer flow.
6. Create a sample ticket.
7. Show automatic classification.
8. Verify the email notification.
9. Explain deployment using Update Set.

## Conclusion

The project demonstrates how ServiceNow Flow Designer can automate school IT ticket classification and notification.
