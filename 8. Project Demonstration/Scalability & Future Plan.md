# Scalability & Future Plan

## Project Title

Auto Ticket Classification using Flow Designer

## Scalability

The project is designed so that additional ticket classifications can be added to the Flow Designer.

New issue types can be added through additional conditions and corresponding Category and Subcategory values.

## Future Enhancements

Possible future improvements include:

1. Adding more IT issue categories.
2. Adding more subcategories.
3. Supporting additional keywords for ticket classification.
4. Adding more automated notifications.
5. Extending the solution for additional school IT support scenarios.
6. Improving the automation for larger numbers of ticket types.

## Maintainability

The Flow Designer provides a structured way to modify the classification logic.

The project configuration can also be transferred using the Update Set XML.

## Conclusion

The solution can be extended as the number and types of school IT support tickets increase.
