# Problem-Solution Fit

## Problem

School IT helpdesk receives different types of IT support incidents.

Manual classification of tickets can take time and may result in inconsistent Category and Subcategory selection.

## Proposed Solution

Use ServiceNow Flow Designer to automatically classify IT helpdesk tickets based on the issue mentioned in the Short Description.

## Problem-Solution Mapping

| Problem | Proposed Solution |
|---|---|
| Manual ticket classification | Automatic classification using Flow Designer |
| Incorrect Category selection | Automatically assign Category |
| Incorrect Subcategory selection | Automatically assign dependent Subcategory |
| Time-consuming ticket processing | Automate ticket classification |
| No automatic confirmation | Send confirmation email to Caller |

## Classification Examples

| Issue | Category | Subcategory |
|---|---|---|
| Wi-Fi / Network | Network | Wi-Fi |
| Projector | Hardware | Projector |
| Forgot Password | Access | Forgot Password |
| Slow Computer | Performance | Slow Computer |

## Expected Result

The proposed solution automates the classification of school IT helpdesk tickets and provides a structured process for handling the requests.
